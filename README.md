# Second Mate

Second Mate is a lean AI coding-workflow coordinator. The repository now
contains a Python 3.12 implementation of approved Direction intake, FS-01, and
the CAP-02A offline trusted-local proof plus the dormant CAP-02C Codex CLI
process adapter, alongside a retained consumed marker and recovery commit from
one historically closed CAP-02B run. Its deleted private event/close artifacts
are not replayable from this checkout. FS-01 carries one supervised, local direct
packet against a deterministic fixture through explicit consent, claim-fit
evidence, durable continuation, and recoverable clean close. CAP-02A adds an
injected mock control-plane path. CAP-02C adds an activation-gated real-process
library boundary that binds one resolved target and current Git revision,
proved only with temporary Git repositories and fake executables; it has never
called a provider and exposes no CLI dispatch route. EVA-03 binds exact-cleanup
authorization to the run-directory and private-root identities; EVA-04 then
closes the cleanup-record persistence crash window with bounded, digest-checked
same-inode records, strict complete-corruption refusal, and durable retry
revalidation. The recovery audits also close stopped-process stdout when a
cancellation drain cannot be prepared, without widening deletion or live-run
authority. CAP-02B previously
manually enveloped exactly one consumed real Codex CLI run. See the
[Direction operator guide](docs/second-mate/DIRECTION-OPERATOR.md) and
[trusted-local contract](docs/second-mate/TRUSTED-LOCAL-OPERATOR.md). The
[MS-02 walkthrough](docs/second-mate/MS-02-OPERATOR-WALKTHROUGH.md) provides a
provider-free hands-on product review without activating the dormant adapter.

Those local capabilities are not the whole intended workflow. The dormant
adapter has no current provider/target activation or real-run evidence and the
repository has no automated Rumble, general Foundation or Delivery Map
execution, deployment, or pilot evidence. The canonical
[Second Mate package](docs/second-mate/README.md) keeps the remaining product
decisions and human authority gates explicit.
