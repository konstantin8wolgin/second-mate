# Second Mate

Second Mate is a lean AI coding-workflow coordinator. The repository now
contains a Python 3.12 implementation of approved Direction intake, FS-01, and
the CAP-02A offline trusted-local adapter proof, plus evidence from one consumed
CAP-02B trusted-local proof run. FS-01 carries one supervised, local direct
packet against a deterministic fixture through explicit consent, claim-fit
evidence, durable continuation, and recoverable clean close. CAP-02A adds only
an injected mock control-plane library path; CAP-02B manually enveloped exactly
one real Codex CLI run without adding a production subprocess implementation or
CLI dispatch route. See the
[Direction operator guide](docs/second-mate/DIRECTION-OPERATOR.md) and
[trusted-local contract](docs/second-mate/TRUSTED-LOCAL-OPERATOR.md).

Those local capabilities are not the whole intended workflow. They have no
production live adapter, automated Rumble, general Foundation or Delivery Map
execution, deployment, or pilot evidence. The canonical
[Second Mate package](docs/second-mate/README.md) keeps the remaining product
decisions and human authority gates explicit.
