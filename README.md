# Second Mate

Second Mate is a lean AI coding-workflow coordinator. The repository now
contains a Python 3.12 implementation of approved Direction intake, FS-01, and
the CAP-02A offline trusted-local proof plus the dormant CAP-02C Codex CLI
process adapter, alongside evidence from one consumed CAP-02B trusted-local
proof run. FS-01 carries one supervised, local direct
packet against a deterministic fixture through explicit consent, claim-fit
evidence, durable continuation, and recoverable clean close. CAP-02A adds an
injected mock control-plane path. CAP-02C adds an activation-gated real-process
library boundary proved only with a temporary fake executable; it has never
called a provider and exposes no CLI dispatch route. CAP-02B previously
manually enveloped exactly one consumed real Codex CLI run. See the
[Direction operator guide](docs/second-mate/DIRECTION-OPERATOR.md) and
[trusted-local contract](docs/second-mate/TRUSTED-LOCAL-OPERATOR.md).

Those local capabilities are not the whole intended workflow. The dormant
adapter has no current provider/target activation or real-run evidence and the
repository has no automated Rumble, general Foundation or Delivery Map
execution, deployment, or pilot evidence. The canonical
[Second Mate package](docs/second-mate/README.md) keeps the remaining product
decisions and human authority gates explicit.
