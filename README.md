# Second Mate

Second Mate is a lean AI coding-workflow coordinator. The repository now
contains a Python 3.12 implementation of FS-01: one supervised, local direct
packet against a deterministic fixture, with explicit consent, claim-fit
evidence, durable continuation, and recoverable clean close.

That slice is not the whole intended workflow. It has no live provider,
automated Rumble, general Foundation or Delivery Map execution, deployment, or
pilot evidence. The canonical [Second Mate package](docs/second-mate/README.md)
keeps the remaining product decisions and human authority gates explicit.
