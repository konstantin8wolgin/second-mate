# Second Mate

Second Mate is a lean, evidence-based coordinator for supervised coding work.

The current local runtime supports two deliberately bounded journeys:

- an [external Rumble to approved Direction handoff](docs/second-mate/RUMBLE-DIRECTION-HANDOFF.md);
- the [FS-01 deterministic direct-packet lifecycle](docs/second-mate/FS-01-OPERATOR.md).

It does not connect to native voice/chat, call a model provider, run arbitrary
commands, schedule work, publish, or deploy.
